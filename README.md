# Goodwell — The Unsettling Landing Page

A responsive, single-page horror experience disguised as a polished business/marketing website. It begins as a calm productivity brand and gradually becomes uncanny as the visitor scrolls.

## Publish with GitHub Pages

1. Download and extract this ZIP.
2. Open the extracted folder. `index.html`, `styles.css`, `script.js`, and `assets/` should be at the top level.
3. Create a new GitHub repository (for example, `goodwell`).
4. Upload the **contents** of this folder to the repository root — not the containing folder itself.
5. In GitHub, open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select `main` and `/(root)`, then Save.
8. Wait for GitHub Pages to publish. Your site will be available at `https://YOUR-USERNAME.github.io/goodwell/`.

## Experience notes

- The marketing facade is clean, responsive and intentionally plausible.
- Unsettling details become more apparent in the testimonial, FAQ, and final sections.
- The final screen escalates after time spent in the ending section and through the visitor's button interaction.
- Ambient drone audio is optional and only starts after the visitor clicks **Sound off**.
- No server, build step, API key, framework, or external image assets are required.
- Google Fonts are used when online; system fallbacks are included.

## Customization

- Change brand copy and section content in `index.html`.
- Adjust colors, typography and layout in `styles.css`.
- Change the timed reveal and ending interactions in `script.js`.

The site does not collect, transmit, or store personal information. A random visitor token is generated and kept locally in the browser only for the final on-screen message.
